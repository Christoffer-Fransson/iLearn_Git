Keybindings - Edit
    CTRL + K -> CTRL + S

Keybindings - Native (default setting)
    CTRL + SHIFT + L - Selects all occurences of the marked text/code.
    CTRL + F2 - same as CTRL + SHIFT + L

WINDOWS:

Select all above cursors: CTRL + SHIFT + HOME (might have to press FN key on laptop)
Select all below cursors: CTRL + SHIFT + END (might have to press FN key on laptop)
